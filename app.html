Supabase DB

Slovník, Import, Statistiky a Odezva

Vlastní databáze slovíček (volitelné). Postup založení účtu a SQL je na záložce Návod. LingQ napojení se nemění.

Klíč anon / publishable z Project Settings → API (ne service_role).

Publishable klíč neumí spouštět SQL sám. Instalace zkontroluje strukturu; když něco chybí, zkopíruje aktuální SQL do schránky a otevře SQL Editor v Supabase — stačí vložit a Run. Pak znovu Zkontrolovat.

Návod · vlastní databáze Supabase (zdarma)

Překlad z LingQ funguje i bez databáze. Supabase potřebujete jen pro Slovník, Import, Statistiky a Odezvu. Free plán na supabase.com stačí.

Upozornění: instalace, aktualizace nebo ruční úpravy SQL mohou poškodit data v databázi (smazání / změna tabulek a funkcí). Před zásahy do už používané DB si ideálně udělejte zálohu projektu v Supabase. Spouštějte jen SQL z tohoto doplňku a jen když víte, co děláte.

    Publishable klíč neumí spouštět SQL přímo — proto jde instalace přes schránku a SQL Editor. Po úspěšné kontrole už databázi z prohlížeče spravovat nemusíte; doplněk si data ukládá sám.
