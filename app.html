Ostatní nastavení

U odkazů je potřeba dvojité kliknutí, aby se stránka neotevřela.

Po načtení stránky: neznámá (mimo DB) modře; 1 nejsilnější žlutá → 4 slabá žlutá; známá (K) a slovíčka v DB bez překladu bez barvy. Jen Supabase DB, ne LingQ API.

Slovíčka, která ještě nejsou v LingQ. Po překladu se karta v LingQ stejně založí.

Zdroj sekce „Další překlady“ ve vyskakovací bublině. ChatGPT se volá až po kliknutí na tlačítko.

V user verzi je při překladu přes LingQ výběr omezen na 10 slov; delší text otevře překladač. ChatGPT (i admin u LingQ) délku neomezuje.

LingQ

Karty a překlady přes LingQ API. Vypnout lze jen s DB + ChatGPT.

Bez LingQ doplněk ukládá slovíčka do Supabase a překládá přes ChatGPT. Po opětovném zapnutí se změny synchronizují do LingQ.

API klíč získáte ve svém účtu LingQ v sekci API key.

Sledovat odezvu po nečinnosti (sekundy) · admin

Jen admin build. Po nečinnosti se v tomto rozmezí náhodně zvolí čas a odešle kontrolní dotaz na LingQ API. Výchozí je 60–80 sekund. Nové karty se při kontrole nezakládají.

ChatGPT

Překlady a alternativy přes OpenAI API (placené)

Ceny jsou za 1 milion tokenů (vstup / výstup) podle ceníku OpenAI. Výchozí je gpt-5-nano.

API klíč získáte na platform.openai.com/api-keys (placené). Postup je na záložce Návod.

Supabase DB

Slovník, Import, Statistiky a Odezva

Vlastní databáze slovíček (volitelné). Postup založení účtu a SQL je na záložce Návod. LingQ napojení se nemění.

Klíč anon / publishable z Project Settings → API (ne service_role).

Publishable klíč neumí spouštět SQL sám. Instalace zkontroluje strukturu; když něco chybí, zkopíruje aktuální SQL do schránky a otevře SQL Editor v Supabase — stačí vložit a Run. Pak znovu Zkontrolovat.

Návod · vlastní databáze Supabase (zdarma)

Překlad z LingQ funguje i bez databáze. Supabase potřebujete jen pro Slovník, Import, Statistiky a Odezvu. Free plán na supabase.com stačí.

Upozornění: instalace, aktualizace nebo ruční úpravy SQL mohou poškodit data v databázi (smazání / změna tabulek a funkcí). Před zásahy do už používané DB si ideálně udělejte zálohu projektu v Supabase. Spouštějte jen SQL z tohoto doplňku a jen když víte, co děláte.

    Publishable klíč neumí spouštět SQL přímo — proto jde instalace přes schránku a SQL Editor. Po úspěšné kontrole už databázi z prohlížeče spravovat nemusíte; doplněk si data ukládá sám.
