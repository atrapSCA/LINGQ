Návod · vlastní databáze Supabase (zdarma)

Překlad z LingQ funguje i bez databáze. Supabase potřebujete jen pro Slovník, Import, Statistiky a Odezvu. Free plán na supabase.com stačí.

Upozornění: instalace, aktualizace nebo ruční úpravy SQL mohou poškodit data v databázi (smazání / změna tabulek a funkcí). Před zásahy do už používané DB si ideálně udělejte zálohu projektu v Supabase. Spouštějte jen SQL z tohoto doplňku a jen když víte, co děláte.

  1. Otevřete supabase.com → Start your project a založte si účet (GitHub, Google nebo e-mail).
  2. Vytvořte nový projekt (New project), zvolte region blízko vás, nastavte heslo databáze a počkejte, až bude Ready.
  3. V projektu otevřete Project Settings → API. Zkopírujte Project URL a klíč anon / publishable (veřejný klíč, ne service_role).
  4. V doplňku na záložce Nastavení vložte URL a publishable klíč (můžete hned i uložit nastavení).
  5. Kontrola: klikněte na Zkontrolovat databázi. Doplněk ověří tabulky, funkce a verzi schématu a napíše, jestli je DB v pořádku, nebo co chybí.
  6. Instalace / aktualizace ze schránky:
    1. Klikněte na Nainstalovat / aktualizovat databázi — SQL se zkopíruje do schránky a otevře se SQL Editor v Supabase.
    2. V editoru klikněte do prázdného pole a vložte obsah schránky: Ctrl+V (Windows) nebo Cmd+V (Mac).
    3. Spusťte skript tlačítkem Run (nebo Ctrl+Enter). Počkejte na úspěšné dokončení bez chyb.
    4. Vraťte se do doplňku a znovu klikněte na Zkontrolovat databázi — má se zobrazit, že je databáze připravená.
  7. Po aktualizaci doplňku znovu použijte Zkontrolovat; když hlásí starší schéma, spusťte znovu instalaci ze schránky (bod výše). Ručně lze spustit i soubory ve složce supabase/ (včetně schema_version.sql).

Publishable klíč neumí spouštět SQL přímo — proto jde instalace přes schránku a SQL Editor. Po úspěšné kontrole už databázi z prohlížeče spravovat nemusíte; doplněk si data ukládá sám.

Návod · ChatGPT API klíč

Pozor: ChatGPT API je placené. Platíte za spotřebované tokeny podle ceníku OpenAI — nejde o předplatné ChatGPT Plus. Doplněk bez tohoto klíče funguje (LingQ); klíč potřebujete jen pro překlady / alternativy přes ChatGPT.

  1. Otevřete platform.openai.com a přihlaste se (nebo založte účet OpenAI).
  2. V nastavení účtu / billingu doplňte platební metodu a kredit — bez kreditu API obvykle nefunguje.
  3. Jděte na API keys → Create new secret key, klíč si hned zkopírujte (znovu se nezobrazí).
  4. V doplňku na záložce Nastavení vložte klíč do pole ChatGPT API klíč a uložte. Pak můžete u nových slovíček / dalších překladů zvolit zdroj ChatGPT a model.

Klíč nikomu neposílejte. Ceník modelů v Nastavení (vstup / výstup za 1 M tokenů), stav k 6. 11. 2026:
